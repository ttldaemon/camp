# Camp

**Camp** is a collaboration platform for developer teams to manage
projects, organize tasks, and communicate in one place.

Teams often rely on separate tools for chat, task tracking, and project
coordination. This fragments conversations, makes responsibilities
harder to track, and can cause important updates to get lost. Camp aims
to bring these workflows together so teams can collaborate more
efficiently, keep track of progress, and focus on building.

Designed for college project teams, hackathon groups, and developer
communities, Camp brings project organization and team communication
into a shared workspace, with AI-assisted productivity and GitHub
integration as part of its broader direction.
